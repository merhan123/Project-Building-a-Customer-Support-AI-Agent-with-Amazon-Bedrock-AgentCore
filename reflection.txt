One design decision was to keep deterministic business calculations outside the language model. The model selects the loyalty tool, but AgentCore Code Interpreter executes the calculation using Python Decimal values. Points are redeemed in 500-point blocks, with a cap of 50% of the original order total. The tier discount is then applied to the remaining subtotal. The result separates the balance after redemption from the balance after earning new points. Live traces exposed a model response that restated the correct $99 tool result as $95. I therefore render the displayed breakdown directly from the structured tool result and persist that same response to memory. This keeps the calculation auditable and prevents narrative arithmetic from overriding sandbox output. If the sandbox is unavailable, the tool clearly labels its tier-only fallback and does not claim that points were redeemed.

A challenge was translating the course's console instructions into working API requests. AgentCore Gateway rejected the suggested target names containing underscores, so the implementation uses hyphens while preserving the supplied Lambda handlers. The managed Knowledge Base also rejected the older S3 data-source configuration. Consulting the AWS documentation showed that it requires a managed connector with S3-specific connection parameters. After correcting this, catalog synchronization completed and a live retrieval returned the electronics return policy. Recording resource identifiers allowed setup to resume without creating duplicate resources.

For production, authenticated customer identity and authorization would be essential. The lab accepts a customer identifier in the payload and uses a Gateway with no inbound authorizer. A production service should derive identity from verified credentials, enforce order ownership in the backend, and make refund operations idempotent. Prompt instructions are not an authorization boundary. The supplied refund Lambda is a demonstration rather than a persistent transaction system. I would also add memory retention controls, appropriate logging redaction, cost monitoring, and automated integration tests before exposing the assistant to real customers.
